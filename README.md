# Battery Charging Tracker - downloads

Battery Charging Tracker is a Windows program for battery shops: check batteries in, track charging and testing, print labels and receipts, and let customers know when their battery is ready. Made by Enphinium Studios.

## Download

**[Get the newest version](https://github.com/therealmrboo/battery-tracker-releases/releases/latest)**, then under **Assets** click **BatteryTrackerSetup-....exe**.

- You need an **install key** to install it. Contact Enphinium Studios if you don't have one.
- Needs Windows 10 (version 1809 or later) or Windows 11, 64-bit.

## Updating

Battery Tracker updates itself: it checks once a day, or choose **Menu > Help > Check for Updates**. On a shop network, **update the main computer first**, then the others.

To update by hand, download the newest installer from the link above and run it on each computer. It updates in place and keeps everything.

## What's on this page

- **Releases**: every version. Each one's installer and `latest.txt` (the signed notice Battery Tracker reads to find updates) are under **Assets**.
- **"Source code (zip)" and "Source code (tar.gz)"** appear under every release because GitHub adds them automatically. They only contain this README file, not the program's code, and can be ignored.

## Help

Email **enphinium@gmail.com**. In Battery Tracker, **Menu > Help > Save Support Info** makes a file you can attach, with how Battery Tracker is set up and its logs (no passwords and no customer list).
